Primary × secondary locator matrix

Parsed records by prefix series and Regional Secondary Locator (latest dataset). Every reference series and RSL letter is shown — all-dot rows and columns are the sparsity signal, not noise; · means zero; ⚠ marks locators observed in the data but absent from reference data. Excluded records are counted beneath the table.

Column profiles

Per-column shape of the latest publication: how many distinct non-empty values each column carries, how many rows populate it, how many leave it empty, and its value range. Emptiness is the signal — a column empty on a quarter of rows, or on every row, is visible at a glance. Distinct counts and ranges consider non-empty values only.

Callsign format taxonomy

Every callsign in the latest publication abstracted to its shape — letters, digits and any space or invisible character collapsed to a pattern — then ranked. The dominant shapes are the standard licence formats; the long tail is where placeholder conventions, casing errors and stray whitespace surface. The full taxonomy is folded into a details block so archived captures keep the complete list.

Callsign quality detectors

Heuristic detectors run over the callsign column of the latest publication, each grounded in a defect class observed in real exports. Counts are detected occurrences, declared but not independently verified; example values make each detector's hits legible, with spaces and invisible characters marked. A zero is a genuine result worth seeing.

Data-quality flags per publication

Counts of per-row flags across every archived open-data publication (vocabulary: flag registry). This table is per open-data publication; FOI-disclosed register snapshots are now run through the same parser and flag machinery too (in the master database's observations table), and their flag and parse-status counts are folded into the standing data-quality rollup and value catalogue, which expand these figures across the whole corpus.
