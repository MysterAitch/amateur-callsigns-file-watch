callsign-record / get the raw data

Every archived file, published verbatim at a stable URL — and the databases folded from them.

The mirror preserves each publication byte-for-byte. Nothing below is derived beyond what the sources state; every derived database carries provenance to the byte. These surfaces are served by the previous, fuller-featured version under /v0/.

browse the archive

Dataset index

Every archived dataset in both collections — Ofcom open-data publications and FOI requests — with the raw, extract and normalised files published verbatim. Each entry’s own page carries its meta.json (sha256 for every file), a Frictionless datapackage.json, and a one-click .zip of everything in that entry.

per-entry: raw files · datapackage.json · meta.json · one-click .zip

Browse by kind of data

Every entry carries one or more dataset types — a register snapshot, an availability pool, a forbidden-suffix list, and so on — each with an overview: what that kind of data is, the shape of a row, its provenance and quirks, and every entry that carries it.

whole-corpus databases

combined.sqlite.gz

One SQLite database of everything: the FOI observations union plus every open-data publication’s normalised rows (register_history). Gzipped for the download.

SQLite · gzipped

foi-observations.csv.gz

The flat union of every callsign-bearing FOI normalised row, as one gzipped CSV. Empty cells conflate not-asserted with asserted-blank; the combined database keeps them distinct (NULL vs empty string).

CSV · gzipped

Per-entry SQLite (one table per CSV)

Each archive entry is also offered as its own SQLite database — one table per CSV — with its size, from that entry’s page in the dataset index.

the claim ledger & provenance

The raw-keyed claim ledger

Every value the mirror derives traces to the source byte that asserts it. The ledger queries that provenance live, in-browser, over HTTP range requests — one row per raw byte, every derivation rule and every source row behind a record.

Data status

What is held right now: the newest publication, the count of publications, and the integrity record for the set this build was generated from.

Data dictionary & schemas

The schemas and vocabularies that make the published datasets interpretable without the repository — linked from the dataset index, alongside the standing reports.
