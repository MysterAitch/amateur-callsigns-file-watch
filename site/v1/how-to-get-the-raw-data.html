callsign-record / get the raw data

Every archived publication, preserved byte-for-byte in the open repository — and the databases folded from them.

The mirror preserves each publication exactly as published. Nothing is derived beyond what the sources state; every derived database carries provenance to the byte. The archived files and the code that folds them are in the public repository. The bundled downloads and the in-browser query surfaces are being migrated to this site; where a surface has not moved here yet, this page points to the repository rather than anywhere off this site.

browse the archive

The archive, in the repository

Every archived dataset in both collections — Ofcom open-data publications and FOI requests — with the raw, extract and normalised files preserved verbatim. Each entry carries its meta.json (a sha256 for every file) and a Frictionless datapackage.json beside the raw bytes.

per-entry: raw files · datapackage.json · meta.json

Reference data & schemas

The vocabularies and schemas that make the published datasets interpretable without the repository — prefix formats, licence categories, the forbidden-suffix union and the flag registry — each documented alongside the data.

whole-corpus databases

combined SQLite & the FOI observations union

One SQLite database of everything — the FOI observations union plus every open-data publication’s normalised rows — and the flat union CSV, are produced at build time by the folding code in the repository. These bundled downloads are being migrated to this site; until then, the builder that produces them is open in the repository.

The folding code

Every derived database is a deterministic projection of the archived bytes. The code that reads the archive and folds each tier is in the repository, so any derived value can be reproduced from the raw files.

the claim ledger & provenance

the raw-keyed claim ledger

Every value the mirror derives traces to the source byte that asserts it — one record per raw byte, every derivation rule and every source row behind a value. The interactive ledger is being migrated to this site; the ledger data and its builder are open in the repository.

The project repository

What is held, how it is folded, and the integrity record for every publication — all in the open, versioned repository this mirror is built from.

licensing & attribution

The data it mirrors is not covered by that licence: every archived file is reproduced from its publisher under that publisher’s own terms — see archive/LICENSE.md for how that applies, and each publisher’s statement and verification links in the repository.
