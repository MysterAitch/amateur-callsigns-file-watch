plain-language reference

Glossary

Plain-language definitions of the terms that recur across the lookup, Explore, Compare, dataset and series pages. Each entry is one clear line, deep-linkable by its #anchor. This is a human-first layer above the column-level data dictionary and flag registry, which remain the authoritative, per-field references.

the model

Three axes, deliberately not conflated

The project describes every piece of its data along three separate questions. They are easy to run together and must not be: a highly authoritative source can still yield a low-confidence value, and a fully processed file says nothing about how sure any single value inside it is. Each axis has its own ladder of rungs, shown below as tier badges in order, and each ladder carries its own colour accent so the three are never mistaken for one another.

1 · Processing progress

Per dataset — how far have we taken this file?

1Read → 2Understood → 3Validated → 4Normalised → 5Enriched

An operational ladder, like build tasks: how far a file has been carried through the pipeline. Surfaced — and computed at deploy from the committed archive — on the data-status tracker, which doubles as the work-queue. A stage that has not run is shown as a fact, never implied complete.

Read
Raw bytes archived and openable: turned into machine-readable rows — a container opened, sheets or CSV extracted. A PDF scan stays not-read until it is transcribed or OCR'd.
Understood
The shape, columns, encoding and meaning are known: the domain fields in the extract are identified and mapped to the canonical shape — which column is the callsign, which the status, which the licence class.
Validated
The extract passes the committed integrity contract — the invariants and sanity gates: line and row accounting reconciles and values parse, enforced by the validators in continuous integration.
Normalised
A canonical normalised view exists, mapped into the shared schema and joinable across snapshots — deterministic transforms only: clean the callsign, carry status and class verbatim, render dates ISO.
Enriched
Derived attributes computed by authoritative reference joins — prefix→country (ITU), RSL→region, suffix→forbidden-suffix membership — with parsed components, quality flags and cross-dataset links attached.

2 · Source authority

Per source — who published it, and how official?

1Official → 2FOI → 3Reference → 4Community → 5Self

Recorded in each dataset's metadata (its meta.json) and shown for every entry in the dataset index. These are not strictly better-or-worse rungs — they describe origin. Authority then combines with how a value was produced to give a claim's confidence (axis 3).

Official
Ofcom's own published open data — the register export it releases periodically as open data.
FOI
Released under a Freedom-of-Information request: Ofcom's disclosure log or the WhatDoTheyKnow request archive.
Reference
Authoritative external standards — the ITU callsign series, published licence conditions, RSGB guidance.
Community
Contributed or collated by the amateur-radio community.
Self
Derived or asserted by this project itself — the lowest-authority origin, and always attributable to a rule or note here.

3 · Claim confidence

Per individual value — how sure are we of this value?

1As-published → 2Computed → 3Looked-up → 4Community → 5Best-guess

Tiered per value in the JSONL claim ledger and surfaced on the Ledger. It is a readout of source authority × how the value was produced: a high-authority source can still yield a low-confidence claim, which is exactly why this axis is kept apart from the other two.

As-published
The raw token exactly as the source gave it — verbatim, untouched.
Computed
Deterministically derived by an attributed rule — for example the cleaned or normalised form of a raw value.
Looked-up
Resolved via a reference table — for example a licence category derived from the product code.
Community
Drawn from community knowledge rather than a published source.
Best-guess
An inferred fallback where nothing better exists — always flagged as such, never presented as fact.
status vocabulary

Register status values

The register's status column records the state Ofcom holds for a callsign. The mirror reports the value verbatim and does not infer policy the data does not state. The three common values below are described in everyday terms; the rarer values that follow are shown honestly as observed but not authoritatively defined.

Allocated
The callsign is on issue — held by a licensee. This is the ordinary "in use" state and by far the most common value in the register.
Reserved
The register marks the callsign as held back or withheld from new issue. The record does not say why or for whom — it can cover, among other things, a corresponding-callsign hold for an existing holder, or an administrative reservation. Treat it as "not currently available for general issue", nothing more specific.
Available (and the "availability" trap)
Two different things share this word, and confusing them leads to wrong conclusions:
  • Status Available — a literal value the register can carry on a row it does hold, asserting that the callsign is free to be issued.
  • Inferred availability — the suffix matrix's "no record" conclusion, drawn when the register holds no row at all for a callsign. Ofcom does not routinely record never-issued callsigns, so no-record suggests, but does not guarantee, availability. A no-record result is a hopeful lead, not the status value Available, and never a promise you can apply for it.
In short: absence of a record is not evidence of availability.
Live
A status value observed in the data. The mirror has not established an authoritative mapping for it — it is carried verbatim and flagged in the value catalogue as a state with no canonical meaning decided. Do not read more into it than the register states.
Forbidden
A status value observed in the data, distinct from the forbidden-suffix data-quality flag. As with Live, no canonical meaning has been established; it is reported verbatim, not interpreted.
Quarantine
A status value observed in the data, with no canonical meaning established by the mirror. Commonly understood in amateur-radio practice as a cooling-off period before a surrendered callsign can be re-issued, but the register does not state this, so the mirror does not assert it.
terms and notation

Terms and notation

Prefix series
The leading block of a callsign that fixes its licence level and era — for example M7 (Foundation), 2E0 (Intermediate), M0 (Full). One series page exists per series, pairing reference facts with current counts.
Licence class — Foundation, Intermediate, Full
The UK amateur licence level a callsign was issued under, in ascending privilege: Foundation (entry level, e.g. the M6/M7 series), Intermediate (e.g. 2E0/2E1 and the M8/M9 series), and Full (e.g. M0). The class governs power limits and permitted activities; a callsign's prefix series usually signals it, though a holder may upgrade class while keeping an older callsign, and Ofcom also issues non-standard classes (club, reciprocal, and so on). The mirror carries the class verbatim wherever a source states it.
RSL — Regional Secondary Locator
The optional letter inserted after the first character to show the UK nation of operation (e.g. E for England, W for Wales, M for Scotland). England is unusual in that it is also the implied default when no RSL is shown, so a bare form such as M7TEE is ambiguous — it may be an England station, or any holder simply not showing their RSL — whereas MW7TEE is unambiguously Wales. The register stores the RSL-less core callsign; a rendering with an RSL is an interchangeable form of the same licence.
Placeholder form (the # notation)
A single display of a callsign that stands for every regional rendering at once, with # marking the RSL slot — so M7TEE, MW7TEE and ME7TEE all normalise to the canonical form M#7TEE, which the mirror uses across the site as a consistent value for comparisons and analyses. It is not a callsign you would transmit.
Suffix
The trailing letters after the digit (the TEE of M7TEE). Searching *TEE shows the availability matrix — the register state of that suffix across every prefix series.
Forbidden suffix
A suffix on Ofcom's August 2019 FOI withheld-suffixes list — unlikely to be newly issued, though existing allocations stand. Carried as a per-row data-quality flag; see the flag registry.
Cleaned
An artefact-safe join key: the callsign uppercased with everything outside A–Z, 0–9 and / stripped, so longitudinal joins survive differences in publisher whitespace and encoding. Duplicates are expected — it is a join key, deliberately not an identity.
Normalised
A consistent view of a raw source: its columns and casing brought into line — derived from the archived original, which is always preserved verbatim alongside it. Normalisation never overwrites the raw bytes.
Canonical form
The single reference spelling a family of equivalent renderings of one callsign collapses to — a trailing space, a lowercase letter or a regional rendering all resolve to the same reference form. It is the form a lookup is matched against, and it mirrors the standard written forms set out in the amateur licence conditions and exam material. The cleaned join key and the placeholder form are how it is derived; the raw form each source published is always kept verbatim alongside it, and the canonical form never overwrites it. See also the plain-English explainers on the anatomy of a UK amateur callsign and invisible characters and how we show them.
Dataset class
The entry-level vocabulary saying what kind of data an archived dataset is — a register snapshot, an availability pool, a forbidden-suffix list, and so on. One dataset may carry several. The classes and their definitions are the authored vocabulary the FOI validator enforces; the dataset-class index lists every archived entry carrying each. Distinct from a value's claim confidence or its source's authority.
Register snapshot
A dataset class: a point-in-time copy of (part of) the register, as disclosed via FOI or published as open data. What it describes is fixed at its vintage; it is not live.
Observation
A single assertion witnessed in an FOI-disclosed dataset — one callsign's status, class or a dated event as that source recorded it. In the master database, NULL means the source never asserted a column; an empty string means it asserted a blank value.
Vintage
The date the data describes — the "as of" moment of a snapshot or list — distinct from when the FOI request was made or answered. It may be a precise date, a coarse month (e.g. 2016-09), or unknown (—).
Declared complete / declared partial
Whether a publication says it covers the whole register or only a subset. This is a declaration of intent, not verified fact: exports declared complete have been observed silently omitting records. Absence from a publication is only ever treated as evidence when that publication declared itself complete — and even then it is a lead to check, not proof.

Definitions in plain language for orientation; the per-field data dictionary, FOI schemas and flag registry remain authoritative. An independent, unofficial mirror — see About.
