views & tools

Other ways in

Statistics — aggregate views over the archived data (no SQL needed): the prefix-series × RSL matrix and data-quality flags per publication, generated at deploy time.

Prefix series — one page per callsign prefix series (no SQL needed): hand-curated reference facts joined with counts from the latest publication.

Dataset index — every archived dataset (open-data publications and FOI disclosures), published with its raw, extract and normalised files at stable URLs, each entry with a machine-readable descriptor, per-entry metrics, and one-click downloads.

Data status — a build-time tracker of every dataset the mirror holds or knows exists, and how far each has been carried through processing.

Glossary — plain-language definitions of the recurring terms: RSL, prefix series, placeholder form, register status values, and the three axes the project describes its data by.

Explore (for SQL users) — run read-only SQL over the published databases in your browser: join the datasets, follow the worked examples, no install needed. A link can carry a query, so a page can point straight at a result — for example the data-quality flag vocabulary opens the console pre-filled and runs it.

how this works
The end-to-end flow, no server in between

This lookup is a proof of concept: it queries a published SQLite database directly from your browser over HTTP range requests — the full end-to-end flow from Ofcom's register, through the mirror's normalisation, component parsing and reference data, to your screen, with no server in between. Full source and provenance are in the repository.

offline use

Use this lookup offline

By default each search fetches only the few kilobytes of the database it needs, so the first load stays light. If you would rather work with no connection — on the air, in the field, or on a poor link — you can download the whole database once and run entirely in your browser afterwards. It stays on this device until a new version is published (which replaces it) or you remove it.

Advanced: the full historical database

The master database carries every archived publication and all FOI observations — much larger (~[[db-size:master]]). Only download it if you need the longitudinal history (register history and FOI-witnessed observations) available offline too.
