# Value catalogue

Every distinct value of the tracked fields across the whole corpus
(open-data publications + FOI observations), with counts and the lanes
that carry it. Regenerated by the report sweep and committed, so a
change here in a PR diff is a drift signal - a new status, a prefix that
should not exist, a fresh vocabulary variant. Values are the *derived /
canonical* surface; nothing is dropped or force-mapped - unmapped values
are shown, never assumed away.

Each figure names WHAT it counts, so a number is never ambiguous:
`records` is rows carrying the value (rows and records are 1:1 here -
the conversion is a bijection); `callsigns` is how many DISTINCT
callsigns those records span (the same callsign recurs across every
publication, so `records` far exceeds it); `allocated` is how many of
those distinct callsigns carry the `Allocated` status somewhere in the
corpus - the live-register slice of the population. `allocated` is not
meaningful for the `status` field itself (the value already IS the
status), so it shows `—` there.

For scale, the teaching example: the corpus's `Allocated` status alone
carries 3,061,134 records from just
115,414 distinct callsigns across 33 held
snapshots - the record count tracks how many snapshots the corpus holds,
not how many callsigns exist.

`sources` is how many distinct publications/entries carry the value:
breadth, not just volume - a value in 10 sources at 1 each reads very
differently from one source at 10,000.
`timeline` is its count across the 9 dated open-data
publications, oldest→newest, each value scaled to its own peak
(`·` = absent from that publication; FOI entries add to `sources` but
not to this axis). A present-then-gone value is visible at a glance.

## Notable

- **Status values with no canonical mapping decided**: `Live` (105,353), `Forbidden` (10,862), `Surrendered` (258), `Terminated` (178), `Quarantine` (2). Seen but not reasoned about as register states - candidates for reconciliation or an FOI on the state vocabulary.
- **Prefix series outside the reference table** (`reference-data/prefix-formats.csv`): `GB` (3,935), `M2` (25). A supposed-to-be-empty prefix that is not empty (e.g. `M2`) is exactly the kind of surprise this catalogue exists to flag.
- **Licence product/class vocabulary drift**: 16 distinct variants across the corpus (7 appear in both lanes). The same class is written differently by source (e.g. `Full` vs `Amateur Full Radio Licence`) - these are passed through VERBATIM today (source fidelity), so this is the explicit, counted list of canonicalisation candidates.

### Temporal character of the special-event family

The special-event / Notice-of-Variation category NAMES suggest different
temporal shapes — `Special Event Station` reads as event-bounded (a
jubilee year, a single commemoration), `Permanent Special Event Station`
and `Special Research Permit` as open-ended — but the register does not
define these terms, so the reading is the name's, not a rule, and the
per-record evidence below is left for the reader to weigh.
The register's own `created_date` (record creation) and
`reserved_to_date` (reservation expiry) BRACKET an event window rather
than state it, and the snapshot day is only month-level, so any window
is attested-or-bracketed, never inferred. Only the register snapshots
that state a reservation-expiry field attest a window, so the counts
below are that field's slice of each category, not its whole population.

| category | nominal character (from the name) | records stating a reservation field | with an end date | left open |
|---|---|---:|---:|---:|
| `Special Event Station` | event-bounded | 3,715 | 3,501 | 214 |
| `Permanent Special Event Station` | open-ended | 53 | 36 | 17 |
| `Special Research Permit` | open-ended | 1 | 0 | 1 |

⚠ The correspondence is a tendency the register does not enforce, flagged rather than smoothed — `Permanent Special Event Station`: 36 records nonetheless carry an end date; `Special Event Station`: 214 records carry none. The window is read per record from the register, never assumed from the category.
