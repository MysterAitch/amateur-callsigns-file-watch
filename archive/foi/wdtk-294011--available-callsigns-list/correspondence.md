## Overview

- **Asked**: an updated list of all unallocated UK amateur radio callsigns.
- **Provided**: in full — `Amateur Available Call signs.xlsx`, "a list of
  all unallocated UK amateur radio callsigns **as of 13 October 2015**";
  three worksheets (extents indicative, from declared dimensions):
  - `Foundation` — ~6,077 rows × cols A:G, available-pool
  - `Intermediate` — ~8,365 rows × cols A:G, available-pool
  - `Full` — ~7,042 rows × cols A:G, available-pool
- **Withheld**: nothing. The response letter is inline on the thread
  (reproduced below); the message carries exactly one attachment.
- **Significance**: the sibling entry wdtk-299321 (response 2015-10-29)
  serves a file with the **same name and byte count but a different
  sha256** — this letter's as-of date (2015-10-13) is the key to resolving
  whether the pair are different snapshots or regenerated exports of the
  same data (see that entry). Note the column extent dropped to A:G in
  this era (from A:H earlier in 2015).
