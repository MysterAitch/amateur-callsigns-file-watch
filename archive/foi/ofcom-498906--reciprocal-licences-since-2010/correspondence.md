## Overview

- **Asked**: how many Amateur Radio Reciprocal Licences have been issued
  since 2010, listing the call signs with date of issue in year order.
- **Provided**: a two-column workbook (`Original Start Date`,
  `Call Sign T-Number`) of 319 reciprocal-licence issue events, dates
  ascending 2010-01-07 → 2016-07-12.
- **Significance**: sibling of
  [`ofcom-498903`](../ofcom-498903--reissued-callsigns-since-2010/) — the
  same requester intake (received 2017-11-26), the same adviser and
  response day (2017-12-22), the same export shape, and the same quirk:
  the data stops in mid-2016 despite the request window running to the
  request date. 178 rows carry stored `23:00:00` times (BST-midnight
  timezone artefacts in the workbook itself), carried verbatim.
